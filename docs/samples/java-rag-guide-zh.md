# Java-RAG 中文使用说明（测试样例）

Java-RAG 是一个纯 Java 实现的检索增强生成工具箱，兼容 Java 8 及更高版本。它不使用 Spring 或任何重量级框架，因此可以直接嵌入银行、政务等传统企业系统，而不必为它引入一整套 Web 框架。

默认的本地模式使用确定性哈希向量和抽取式生成器。这种模式不需要云端 API Key，也不需要提前下载模型，适合在离线环境中验证完整的检索链路。

文档进入系统后会先被解析，再被切分成若干片段。每个片段都会计算一次向量，并写入内存索引。片段切得好不好，直接决定检索能不能命中，也决定最终答案里的引用是否完整。

当用户提问时，问题同样会被向量化，并与所有片段计算相似度。系统取相似度最高的前 K 个片段作为上下文，只把这些片段送入生成阶段，从而避免把无关内容混进提示词。

最终答案会附带引用编号，右侧面板同步展示命中的文档名、片段序号、相似度和原始片段。答案与证据来自同一次检索结果，因此不会出现答案引用了一段并不存在的原文的情况。

如果需要接入真实的大模型，可以启动 Ollama 配置，把生成阶段替换成本地模型。此时检索、分块与引用逻辑保持不变，只有生成器发生变化。

需要注意的是，中文没有空格分词，按固定字符数硬切会把一句话从中间截断。检索出来的证据如果以半句开头，阅读体验很差，答案的引用完整性也会下降。因此对中文文档应当采用按标点切句、再按长度合并的策略。
